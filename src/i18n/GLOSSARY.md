## Style / Estilo

- **English**: US English, sentence case for labels and buttons ("New tab", not "New Tab"), short and direct, imperative for instructions ("Click to mark it").
- **Português**: português do Brasil, "você", sentence case, imperativo ("Clique para marcar").
- The Spanish source uses Uruguayan *voseo* ("hacé clic", "agregá"): translate to a plain imperative.
- Keep product and program names as they are: AlphaTerm, Claude Code, Codex, Antigravity (agy), OpenCode, Docker, Git, PowerShell, cmd, WSL, WebView2.
- Keep `{variables}`, keyboard shortcuts (`Ctrl+Shift+T`), commands, paths and code exactly as they are. Key names: Espacio → Space / Espaço, Mayús → Shift.
- Spanish «comillas» → "quotes" in English and Portuguese.
- Keep the same ending punctuation (period, colon, ellipsis) and a similar length: many labels have little room.
